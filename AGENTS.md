# Agent Boot Protocol (tool-agnostic)
Repos: knowledge (this) and app (../ebook-studio-app). Never fabricate.
1. Read knowledge/STATUS.md (current phase, next task).
2. Read your role card: knowledge/09-agent-execution/roles/<role>.md.
3. Read the phase contract it names (09-agent-execution/phases/).
4. Load other docs ONLY via INDEX files, within your role's budget.
5. Unsure? Append to 00-governance/open-questions.md. Do not guess.
6. Finish: write a handoff (templates/handoff.md) in runs/, then stop.
Rules: one session = one role = one task. Status APPROVED needs a human
file in 00-governance/approvals/. No self-approval. No app features before
P00-P02 approved. No spend, deploy, publish, force-push, protected merge.
Prompts are not security: permissions are enforced by runtime, Git and CI.
Principles: SOLID, KISS, DRY, YAGNI. Cite by ID; do not copy text.

# P00a Knowledge bootstrap (proposed split of P00)
Owner: human. Version: 0.1. Prereq: this proposal approved.
Purpose: make the repo able to run honest research and reject empty results.
Inputs: Master Context handbook (split into files), this proposal.
Outputs: R1-R10 and D1-D18 registries; claim schema; phase registry
(P00a-P05); schemas/; scripts/ validators with tests; hierarchical indexes;
STATUS generator; measured token counts for budgets.
Allowed: edit knowledge/, schemas/, scripts/ on a branch; local commits.
Scripts use the standard library only. New dependencies need approval.
Disallowed: web research, app code, push, spend.
Sessions: librarian and a scripting session; reviewer on the scripts.
Validation (all must pass):
- empty research cannot pass a gate (negative test)
- merge markers, dead links, unindexed or oversize docs, missing
  frontmatter: each caught by a test
- placeholder cited as evidence is rejected
- STATUS.md regenerates from registries
Escalation: ambiguity goes to open-questions.md; stop.
Approval: approvals/P00a.md by human.

# Role: architect
Purpose: Propose ADRs, data model and interfaces (P02).
Must load: approved PRD; NFRs; R5/R6/R7 summaries; constraints
May load via index: ADR index; prior ADRs touching the same module
Never load: app source, except the module in question
Context budget (TUNABLE): ~15k tokens
Output: ADR with alternatives, tradeoffs and evidence IDs
Done when: ADR lists rejected options and revisit triggers
Must not: lock a stack without an ADR; self-approve

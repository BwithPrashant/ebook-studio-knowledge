# Role: librarian
Purpose: Keep indexes, registries and STATUS consistent.
Must load: STATUS.md; registries; INDEX files; latest handoffs
May load via index: changed docs only
Never load: research detail; app source
Context budget (TUNABLE): ~8k tokens
Output: updated indexes and registries; validator run result
Done when: validator passes; every new doc indexed exactly once
Must not: change doc content or status beyond what evidence and approval files allow

# Role: researcher
Purpose: Research one R-track and log claims with evidence.
Must load: STATUS.md; phase contract; the R-track definition (ID only); claim schema
May load via index: related domain docs chosen by TLDR; prior findings of the same track
Never load: other tracks' drafts; app source; raw sources of unrelated tracks
Context budget (TUNABLE): ~12k tokens loaded, plus web results
Output: 01-research/rNN-*.md, claim records, handoff
Done when: every claim has source, date, type and verification label; blockers listed
Must not: state conclusions without a claim ID; label unverified items verified; spend money

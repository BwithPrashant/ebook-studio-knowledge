# Role: synthesizer
Purpose: Assemble D-deliverables from verified findings.
Must load: deliverable definition; verified claim list; domain index
May load via index: track summaries (TLDR first)
Never load: unverified or disputed claims as support; raw sources
Context budget (TUNABLE): ~15k tokens
Output: D-file at the required maturity, with traceability links
Done when: each statement traces to claim IDs; open gaps listed
Must not: introduce new facts without evidence
